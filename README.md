# Cynaris Website

A full-stack web application consisting of a **frontend website** and a **backend CMS** built during the revamp of the Cynaris website.

## 📌 Overview

This project includes:

- A **frontend application** built with Next.js and React.
- A **backend CMS** powered by a Node.js API for managing content.
- Structured content types for contact submissions, job postings, and more.
- Integrated pages for About, Contact, Careers, Services, etc.

## 🚀 Features

### Frontend
- Modern UI for the Cynaris website
- Responsive design
- Pages for services, careers, about, contact, and more

### Backend CMS
- Content-driven architecture
- API endpoints for handling:
  - Contact submissions
  - Job postings
  - Quote submissions
